# scripts/

Skrip Python untuk pascapengolahan data dan visualisasi:

- `plot_band_dos.py` — memplot struktur pita energi & DOS dari hasil `bands/` dan `dos/`
- `plot_optic.py` — memplot fungsi dielektrik & absorpsi optik dari hasil `optic/`
- skrip transport BoltzTraP2 (mengacu pada kode yang sudah kamu miliki)

Semua skrip menggunakan style sheet `matplotlib/sci.mplstyle` dan menyimpan hasil ke
folder `figures/`.

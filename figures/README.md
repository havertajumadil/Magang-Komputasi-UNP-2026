menggunakan style sheet dari `matplotlib/sci.mplstyle`. Contoh isi:

- `optical_absorption.png` / `.pdf` — spektrum absorpsi optik
- `seebeck_conductivity_pf.png` / `.pdf` — properti transport termoelektrik vs suhu
